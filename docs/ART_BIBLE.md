## 1. แนวคิดหลัก: "บ้านซีด → ผีพอใจ → สีกลับมา"
- **ปัจจุบัน** (บ้านที่ถูกรื้อ): สีหม่นมืด เหงา — แต่ยังเห็นรูปทรงชัด
- **ความทรงจำ** (สิ่งที่กล้องวิญญาณเห็น): สีอำพันโปร่งแสงเรืองแสง — สีเดียวที่ "สด" ในห้องที่ยังไม่จัด
- **ห้องที่ผีรับแล้ว:** สีกลับมาสดเต็ม Palette — รางวัลทางสายตาของการเล่น
- ภาพอ้างอิงที่อนุมัติ: `MIX-before-restore-v2-approved.png` (ก่อน) · `MIX-after-restore.png` / `AD1-cozy-toon.png` (สีหลังรับห้อง)

## 2. รูปทรงและการแรเงา
- **Low-poly** ทรงเรียบ ผิวเรียบไม่มีรายละเอียดเล็ก — อ่านรูปทรงจาก Silhouette
- **Cel Shading 3 ระดับ** (มืด / กลาง / สว่าง) ขอบระดับคม
- **เส้นขอบเข้ม** (Inverted Hull หรือ Post-process ใน URP — ตัดสินใน Prototype ตาม Performance) สี `#1b1420` · ความหนาคงที่บนจอโดยประมาณ
- สัดส่วน: เฟอร์นิเจอร์จริงขนาดคน (ประตู 2.0–2.1 ม., เพดาน 2.6–2.8 ม.) · ตัวละครหัวโตเล็กน้อย (~1.15×) · ของที่ต้องจัดมีขนาด "อ่านได้จากระยะ 3–5 ม."

### 3.2 สภาพ "ซีด" (บ้านปัจจุบัน)
- ความอิ่มสี (Saturation) **× ~0.24** และความสว่าง (Value) **× ~0.6** ของ Palette สด (ค่าจาก Test Render D-017 ⚙)
- ทำผ่าน **Shader ร่วม** ที่มีพารามิเตอร์ `Restoration` ราย "ห้อง" (0 = ซีด, 1 = สด) — ห้ามทำ Material แยกสองชุด
- การเปลี่ยนเมื่อผีรับห้อง: ไล่ `Restoration` 0 → 1 ใน ~2–3 วินาที ⚙ เริ่มจากจุดที่ผีอยู่ แผ่ออก

### 3.4 หลักการ
- จุดนำสายตาในห้องซีด: แสงอุ่นจากโคมไฟ + ของสำคัญบางชิ้นที่ "ไม่ซีด" (เช่น กล่องของบริษัท ยูนิฟอร์มผู้เล่น)
- ไม่ใช้สีอย่างเดียวสื่อสถานะ — ต้องมีรูปทรง/ไอคอนกำกับ (D-012)

## 4. แสง หมอก Post-processing
- **โซนแสง:** อุ่นในบ้าน (โคมไฟ `#ffb35c`) ตัดกับแสงจันทร์ฟ้า (`#9fbfff`) ผ่านหน้าต่าง
- **หมอกบาง** เฉพาะบางห้อง/ทางเดิน ไม่ใช้ Volumetric หนักทั้งบ้าน (Performance — MASTER_PROMPT 6.4)
- **Vignette** เข้มปานกลาง · Color Grading ทำให้เงาอมฟ้าเล็กน้อย
- **ความมืดต้องไม่บังของที่จำเป็น:** ของที่ต้องจัดต้องมองเห็นได้ที่ค่าความสว่างมาตรฐานของหน้าปรับความสว่าง (D-012)
- ห้องที่ผีรับ: แสงอุ่นขึ้นเล็กน้อยพร้อมสี
- ลำดับการตัดสินเทคนิค (Baked vs Real-time, Light Probes) — ทำใน Prototype ตามผลวัด

## 5. ตัวละครผู้เล่น (D-018)
- ร่างกาย + Humanoid Rig + แอนิเมชันจากแพ็ก CC0 (แนวทาง: Quaternius Universal Base Characters + Universal Animation Library ฉบับฟรี หรือ Kenney Animated Characters) — **อ่าน License ในไฟล์ก่อนใช้**
- ชิ้นที่ออกแบบเอง (Blender): **หมวกแก๊ปบริษัทใบโต** (Silhouette หลัก), ชุดเอี๊ยม, เป้, ไฟฉายติดหมวก, ป้ายชื่อ
- ยูนิฟอร์มสี "ไม่ซีด" — หาเพื่อนเจอในบ้านมืด · สีชุดเปลี่ยนได้ 4 แบบใน v0.1
- ของแต่งตัวติดกับกระดูก Head/Spine ด้วยจุดยึดมาตรฐาน

## 6. ผี (D-019)
- **ฐาน:** ร่างผ้าคลุมทรงกลมมน โปร่งแสง (Emission + Alpha) ลอยเหนือพื้น ชายผ้าเป็นคลื่น
- **ใบหน้า:** ตา/ปากแบบเรียบ แสดงอารมณ์ชัด (สงบ / หงุดหงิด / โกรธ / ขอบคุณ)
- **ชิ้นส่วนประจำตัว:** คุณยาย = แว่น มวยผม ผ้าคลุมไหล่ · ลุง = หนวด ผ้าขาวม้า · ป้าครูฝึก = แว่นสายคล้อง กระดานจดงาน
- **ตอนโกรธ (ขั้น 3):** ตาโบ๋ ร่างยืดสูงผิดสัดส่วน ชายผ้าขาดเป็นริ้ว สีอำพัน → แดง — ต้อง "หลอนจริง" ตรวจด้วยภาพ Render/Playtest
- การเคลื่อนไหว: ลอยแกว่งช้า (Procedural) · ผีขี้อายกระตุกเมื่อถูกมอง

## 7. ฉาก (D-020)
- บ้านไทย/เอเชียยุค 80–90 ในเมืองสมมติ: บ้านไม้ใต้ถุนสูง, ทาวน์เฮาส์เก่า (v0.1) · ห้องแถวร้านโชห่วย (ภายหลัง)
- **ของย้อนยุคชิ้นเด่น (ปั้นเอง):** ทีวีจอนูนมีเสาอากาศ, พัดลมตั้งพื้น, ตู้กับข้าวมุ้งลวด, ปฏิทินแขวน, วิทยุ, เครื่องเล่นเทป, โต๊ะหมู่, เก้าอี้หวาย, กระติกน้ำ, กล่องลังของบริษัท
- **ของทางศาสนา/ความเชื่อ:** เป็นของตกแต่งเท่านั้น ยกไม่ได้ ไม่แตก ไม่ปลิว ไม่ใช้เป็นมุก
- ชื่อซอย/ร้าน/ป้ายเป็นชื่อแต่ง ไม่อ้างสถานที่จริง
- Environmental Storytelling: รูปถ่ายครอบครัว ของใช้ส่วนตัวของผี บอกเรื่องราวของเจ้าของบ้าน

## 9. ขั้นตอนนำ Asset CC0 เข้าสไตล์ (ทำซ้ำได้ — MASTER_PROMPT 6.1/6.2)

1. **ตรวจแหล่งและ License:** ดาวน์โหลดจากแหล่งที่อนุญาตเท่านั้น (Kenney, Quaternius, Poly Pizza, ambientCG, Poly Haven) · เปิดไฟล์ License ในแพ็ก · ยืนยันว่าเป็น CC0 — ไม่ใช่ → หยุดและถามผู้ใช้
2. **บันทึกทันที:** เพิ่มแถวใน `THIRD_PARTY_ASSETS.md` (ชื่อ ผู้สร้าง URL License วันที่ ไฟล์ในโปรเจกต์) และ `docs/ASSET_TRACKER.md` (สถานะ Placeholder/Final)
3. **เก็บต้นฉบับไม่แก้:** วางไฟล์ต้นฉบับใน `Assets/ThirdParty/<แหล่ง>/` (เช่น `Kenney/FurnitureKit/`) — **ห้ามแก้ไฟล์ในโฟลเดอร์นี้**
4. **ปรับขนาด:** ใช้ค่าสเกลมาตรฐานต่อแพ็ก (เช่น Kenney Furniture Kit ≈ ×1.85 ให้โซฟาสูง 0.85 ม. — ค่าจาก Test Render ⚙) ทำใน Prefab ของ `_Game` ไม่ใช่แก้ไฟล์ต้นฉบับ
5. **เปลี่ยนวัสดุ:** แทนวัสดุต้นฉบับด้วย **Material ร่วมของเกม** (Shader Cel + Outline + `Restoration`) โดยแมปตามบทบาท (ไม้ / ไม้เข้ม / ผ้าหลัก / ผ้ารอง / โลหะ / ต้นไม้ / กระดาษลัง) → สีจาก Palette ข้อ 3.1 · เครื่องมือ: Editor Script ใน `Assets/_Game/Scripts/Editor/` ที่แมปชื่อวัสดุ → บทบาท (Kenney ใช้ชื่อเช่น `wood`, `woodDark`, `carpet`, `metal`, `plant`)
6. **Kitbash เมื่อจำเป็น:** ถ้าต้องดัดแปลงรูปทรง ให้ทำใน Blender โดยไฟล์ `.blend` อยู่ใน `ArtSource/Blender/` แล้ว Export FBX เข้า `Assets/_Game/Art/Models/` (MASTER_PROMPT 0.1)
7. **สร้าง Prefab ของเกม** ใน `Assets/_Game/Prefabs/` พร้อม Collider ที่เหมาะกับการยก (ทรงง่าย) และข้อมูลน้ำหนัก/แตกได้
8. **ตรวจภาพ:** Render ในฉากทดสอบมาตรฐาน (ห้องอ้างอิงแสงซีด + แสงสด) เก็บภาพใน `docs/screenshots/` ก่อนนำเข้าฉากจริง (MASTER_PROMPT 6.3)
