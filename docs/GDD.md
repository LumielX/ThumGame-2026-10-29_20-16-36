## 1. วิสัยทัศน์

**Spirit Movers** คือเกม 3D Co-op Horror Comedy 1–6 คน ที่ผู้เล่นเป็นพนักงานบริษัทขนย้ายเล็ก ๆ ซึ่งรับงานแปลก ๆ: **จัดบ้านคืนให้ผี** บ้านเก่าถูกรื้อ ถูกย้ายของ ผีเจ้าของบ้านจึงอาละวาด ทีมต้องจัดห้องให้กลับไปเหมือน "ความทรงจำ" ของผี — ผีจึงสงบ และ **สีของบ้านที่ซีดจางจะกลับมา**

ประโยคเดียว: *"ยกโซฟาให้ผีพอใจ ก่อนผีจะยกคุณออกจากบ้าน"*

ความรู้สึกที่ต้องการ (MASTER_PROMPT 1.1):
- หัวเราะกับความผิดพลาดของเพื่อน (ยกของติดประตู สั่งผิดซ้ายขวา โดนผีลากเข้าตู้)
- ช่วยกันคิด — คนหนึ่งเห็นความทรงจำ คนอื่นต้องทำตามคำบรรยาย
- ระทึกจากผีที่โกรธขึ้นเรื่อย ๆ โดยไม่พึ่ง Jumpscare
- อบอุ่นเล็กน้อยตอนจบงาน — ผีแต่ละตัวมีเรื่องราว และบ้านกลับมามีสี
- ไม่ลงโทษหนัก — แพ้แล้วยังได้ค่าจ้างบางส่วน ไม่เสียของถาวร

## 2. ผู้เล่นเป้าหมาย
- **หลัก:** กลุ่มเพื่อน 2–4 คนที่เล่นด้วยกันผ่าน Voice Chat ช่วงค่ำ ครั้งละ 20–90 นาที
- **รอง:** ผู้เล่นคนเดียวที่ชอบปริศนาเชิงพื้นที่และบรรยากาศหลอนเบา ๆ
- ภาษาไทยเป็นหลัก (ค่าเริ่มต้น) รองรับอังกฤษ · Windows 64-bit
- ไม่ต้องมีทักษะเกมยิง/แอ็กชัน — ทักษะหลักคือสังเกต สื่อสาร และจัดของ

## 3. จุดขาย (Unique Selling Points)
1. **ปริศนาความทรงจำ:** เป้าหมายคือ "จัดให้ถูก" ไม่ใช่ขนของไปขายหรือระบุชนิดผี — ผีเป็นทั้งลูกค้าและภัยคุกคาม
2. **กล้องวิญญาณ:** คนถือกล้องเห็นภาพซ้อนของอดีต คนอื่นต้องทำตามคำบรรยาย → การสื่อสารผิดพลาดกลายเป็นมุก
3. **"บ้านซีด → ผีพอใจ → สีกลับมา":** ความคืบหน้ามองเห็นด้วยสีของบ้านทั้งหลัง
4. **บ้านไทย/เอเชียยุค 80–90:** ของย้อนยุคที่ผู้เล่นคุ้นเคยกลายเป็นปริศนาและมุก
5. **ผีคืออดีตเจ้าของบ้าน:** ผีแต่ละตัวมีบุคลิก นิสัยการแกล้ง เสียงฮัม และเรื่องราวในอัลบั้ม

> ข้อสังเกตตลาด (02-names.md): มีเกมเล่นคนเดียวที่ธีม "ฟื้นฟูบ้านเพื่อผี" อยู่แล้ว จุดต่างของเราคือ Co-op + ฟิสิกส์ + ผีที่โกรธและไล่ล่า และต้องสื่อสารให้ชัดว่าไม่ใช่เกม "ขนของไปขาย" แบบ R.E.P.O. (D-002)

## 4. Core Loop (D-003)

### 4.1 Loop ระดับงาน (หนึ่งรอบ ~15–20 นาที ⚙)
```
บรีฟในรถตู้ ─► เข้าบ้าน ─► สำรวจ + หาเบาะแสความทรงจำ ─► จัดห้อง ─► เรียกผีตรวจ (ผีพยักหน้า)
     ▲                                                              │
     │                                         ผีรับห้อง → สีห้องกลับมา (ความโกรธลดลง)
     │                                                              │
  ค่าจ้าง ◄─ Results ◄─ ขึ้นรถตู้ ◄─ ทำพิธีส่งผี (ผีรับครบ) หรือ ออกก่อน หรือ ถูกไล่ออก
```

### 4.2 Loop ระยะยาว
งานสำเร็จ → เงินในเกม + ความคืบหน้ายศ + หน้าอัลบั้มผี → ซื้อของแต่งตัว / ปลดล็อกบ้านและงานยาก → รับงานต่อ

### 4.3 เงื่อนไขจบงาน
| ผล | เงื่อนไข | ค่าจ้าง ⚙ |
|---|---|---|
| **สำเร็จเต็ม** | ผีรับทุกห้องที่จำเป็น → พิธีส่งผี (ผีขอบคุณ ร่างจางหายแบบอบอุ่น) | 100% + โบนัสรีวิวดาว |
| **ออกก่อน** | ทีมขึ้นรถตู้และกด "ปิดงาน" เมื่อไรก็ได้ | ตามสัดส่วนห้องที่ผีรับแล้ว |
| **ถูกไล่ออก** | ความโกรธถึงขั้นสุดท้าย หรือทุกคนถูกขังพร้อมกัน → ทุกคนปลิวออกนอกบ้านแบบ Ragdoll | ตามสัดส่วนห้องที่รับแล้ว × 50% |

ไม่มีการเสียของ/เงิน/ยศถาวรในทุกกรณี (MASTER_PROMPT 1.1)

### 4.4 ระดับงาน (v0.1 มี 2 ระดับ)
| | ปกติ | ยาก (ปลดล็อกยศ 3) |
|---|---|---|
| ห้องที่ต้องจัด | 3 | 4–5 |
| ของที่ถูกย้าย/ห้อง ⚙ | 3–4 | 5–6 |
| ความเร็วความโกรธ ⚙ | ×1.0 | ×1.4 |
| ประเภทปัญหา | ถูกย้าย, ซ่อน | + ลำดับ, ถูกสิง (+ ของหลอกถ้าทัน) |

ขนาดงานปรับตามจำนวนผู้เล่นด้วย (D-011): จำนวนห้อง/ของ เกณฑ์ความโกรธ และความเร็วผี มีตารางคูณตามจำนวนคน 1–6 ⚙

## 5. ปริศนา (D-004)

### 5.1 แนวคิด "ช่องความทรงจำ"
- บ้านแต่ละหลังออกแบบ **ช่องความทรงจำ (Memory Slot)** ไว้มากกว่าที่ใช้จริง — แต่ละช่อง = ของชิ้นหนึ่ง + ตำแหน่ง/ทิศทางที่ถูก + ระยะคลาดเคลื่อนที่ยอมได้ ⚙
- เริ่มงาน: ระบบสุ่มเลือกช่องที่ใช้ แล้ว "รื้อ" บ้าน (ย้าย ซ่อน วางผิดทิศ สลับห้อง) → บ้านเดิมแต่คำตอบใหม่
- **ตัดสินจากสภาพห้อง** ไม่ใช่ลำดับการกด → แก้ได้หลายวิธี

### 5.2 วิธีรู้ว่าห้องเดิมเป็นอย่างไร
1. **กล้องวิญญาณ** (เครื่องมือหลัก): ยกขึ้นส่อง → เห็นภาพซ้อนสีอำพันโปร่งแสงของของในตำแหน่งเดิมช่วงสั้น ๆ **เฉพาะคนถือ** · ฟิล์มจำกัดต่องาน ⚙ · ส่องบ่อยผีหงุดหงิด · ส่งต่อเพื่อนได้
2. **รูปถ่ายชิ้นส่วน / เบาะแสตรรกะ** (ชั้นเสริม): สำหรับของที่กล้องส่องไม่เห็น เช่น ของที่ "ซ่อนในความทรงจำ" (ในลิ้นชัก ใต้เตียง) — เก็บได้ในบ้าน แสดงบนใบสั่งงาน
3. **ผีพยักหน้า (กริ่งเรียกผี):** กดกริ่งในห้อง → ผีเคาะ/กะพริบไฟเท่ากับ **จำนวนของที่วางถูก** ไม่บอกว่าชิ้นไหน (แบบ Mastermind) · เรียกบ่อยผีหงุดหงิด
4. **ผีรับห้อง:** เมื่อของสำคัญในห้องถูกครบตามเกณฑ์ ⚙ ผีรับห้องอัตโนมัติ → ตราประทับบนใบสั่งงาน + สีห้องกลับมา + เสียง Sting อบอุ่น

### 5.3 ประเภทปัญหาในห้อง
| ประเภท | ตัวอย่าง | v0.1 |
|---|---|---|
| ถูกย้าย | อาร์มแชร์ไปอยู่อีกห้อง หันผิดทาง | ✅ |
| ถูกซ่อน | กรอบรูปซ่อนใต้เตียง | ✅ |
| ลำดับ | ต้องย้ายตู้ก่อนจึงเห็น/วางของหลังตู้ | ✅ |
| ถูกสิง | พัดลมถูกสิงส่ายหนี ต้อง "ปลอบ" (ไหว้/ร้องเพลงฮัมตามผี/ส่องกล้อง) ก่อนยกได้ | ✅ |
| ของหลอก | ของที่ไม่เคยอยู่ในบ้าน ต้องเอาออก | ถ้าทัน |

### 5.4 Hint
ติดนาน ⚙ → วิทยุหัวหน้าเสนอคำใบ้ 3 ระดับ (กว้าง → เจาะจง → ชี้ตำแหน่ง) แลกค่าจ้างลดลงเล็กน้อย ⚙

### 5.5 ตัวอย่างห้อง (บ้านไม้ใต้ถุนสูง — ห้องนั่งเล่นของคุณยาย)
ความทรงจำ: คุณยายนั่งเก้าอี้หวายข้างหน้าต่างเพื่อดูทีวีจอนูน · พัดลมหันหาเก้าอี้ · ปฏิทินแขวนเปิดหน้าเดือนเกิดหลานสาว · รูปครอบครัวแขวนตรงกลางผนัง
สภาพตอนรื้อ: เก้าอี้หวายอยู่ห้องครัว · ทีวีหันเข้าผนัง · พัดลมถูกสิงส่ายหัวหนี · รูปครอบครัวซ่อนในตู้กับข้าว · ปฏิทินหล่นอยู่ใต้โต๊ะเปิดผิดเดือน (เบาะแส: รูปถ่ายชิ้นส่วนที่มีวันเกิดหลาน)

## 6. ผี (D-005, D-006, D-019)

### 6.1 แนวคิด
ผีคือ **อดีตเจ้าของบ้าน** — ไม่ชั่วร้าย แค่สับสนและโกรธที่บ้านถูกรื้อ · ร่างฐานเดียวกันทุกตัว: ผ้าคลุมโปร่งแสง ตา/ปากแสดงอารมณ์ + ชิ้นส่วนประจำตัว · **ชนิดผี = บุคลิก** ที่บังคับกลยุทธ์ต่างกัน

### 6.2 ความโกรธ 5 ขั้น (ทุกผี)
| ขั้น | พฤติกรรม | สัญญาณเตือน |
|---|---|---|
| 0 สงบ | ลอยดูผู้เล่น ฮัมเพลงปกติ | เสียงฮัมนุ่ม สีอำพันอ่อน |
| 1 หงุดหงิด | **แกล้ง** ตามนิสัย (D-006) | ฮัมเพี้ยนเล็กน้อย ไฟกะพริบ |
| 2 โมโห | ไฟดับเป็นช่วง ประตูล็อก ของปลิวเบา ๆ | ไอปากขาว วิทยุซ่า |
| 3 อาละวาด | **ออกล่า** — จับแล้วลากเข้าตู้ความทรงจำ | ฮัมกลายเป็นเสียงต่ำ ร่างยืด ตาโบ๋ สีแดง |
| 4 ไล่ออก | ทุกคนปลิวออกนอกบ้าน — จบงาน | — |

- **เพิ่มเมื่อ** ⚙: ทำของแตก, วางผิด, เสียงดัง (วิ่ง ของตก เสียงพูดดังสำหรับผีหูไว), ส่องกล้อง/เรียกผีบ่อย, และเพิ่มช้า ๆ ตามเวลา
- **ลดเมื่อ** ⚙: ผีรับห้อง, Emote "ไหว้ผี" (ห้องละครั้ง), ผู้เล่นทั้งหมดอยู่นิ่งเงียบช่วงหนึ่ง
- ไม่มีหลอดความโกรธบนจอ (D-023) — อ่านจากสัญญาณ + หน้าผีบนใบสั่งงาน · Accessibility เปิดไอคอนบนจอได้

### 6.3 ถูกจับ (ตู้ความทรงจำ)
ผู้เล่นถูกลากเข้าตู้ (มุมกล้องบุคคลที่สาม D-014) → มองเห็นเพื่อน เคาะตู้ให้เพื่อนได้ยิน · เพื่อนช่วยเปิดตู้ได้ (ต้องทำของในห้องนั้นให้ถูก 1 ชิ้น ⚙ หรือส่องกล้องใส่ตู้) · หลุดเองหลัง ~45 วินาที ⚙ แลกค่าจ้าง · Solo หลุดเร็วขึ้น ~20 วินาที และผีสงบลงหนึ่งขั้น (D-011)

### 6.4 ผีใน v0.1
| ผี | ตัวตน | บุคลิก/กลไก | การแกล้ง (ขั้น 1) ตัวอย่าง | กลยุทธ์ที่บังคับ |
|---|---|---|---|---|
| **คุณยายบุญเรือน** (ชื่อสมมติ ⚙) | หญิงชราเจ้าของบ้านไม้ใต้ถุนสูง แว่นตา มวยผม ผ้าคลุมไหล่ ชอบดูละครทีวีข้างหน้าต่าง | **ขี้อาย:** ขยับ/ไล่ล่าเฉพาะตอนไม่มีผู้เล่นคนไหนมอง | สลับของสองชิ้นตอนทุกคนหันหลัง · ปิดทีวีเอง · ซ่อนแว่นของตัวเองแล้วบ่น | ต้องมีคน "เฝ้ามอง" ผี ขณะที่คนอื่นทำงาน |
| **ลุงสมหวัง** (ชื่อสมมติ ⚙) | ชายวัยกลางคนเจ้าของทาวน์เฮาส์ หนวดงาม ผ้าขาวม้า ชอบฟังวิทยุลูกทุ่ง | **หูไว:** ล่าตามเสียง (ฝีเท้าวิ่ง ของตก **เสียงพูดดังในไมค์** D-010) | ทำให้ผู้เล่นสะอึกเสียงดัง (ดึงผีมาเอง) · เปิดวิทยุเสียงดัง · ทำของบนชั้นหล่น | ต้องยกเบา ๆ เดินช้า พูดเบา ใช้ Ping แทนเสียง |
| **ป้าแจ่มจันทร์** (ผีครูฝึก ⚙) | ผู้ก่อตั้ง Spirit Movers ที่ตายไปแล้วแต่ยังมาคุมงานพนักงานใหม่ | ใจดีแต่ขี้บ่น · "แกล้งโกรธ" ให้ดูสัญญาณโดยไม่ลงโทษ | — | ใช้ในงานฝึกงานเท่านั้น |

ผีทั้งสอง (ยกเว้นครูฝึก) สุ่มจับคู่กับบ้านได้ → ความทรงจำของบ้านปรับตามผี (เช่น ผีลุงในบ้านไม้ = บ้านเกิดของลุง) ⚙ ต้องเขียนเนื้อหาความทรงจำรองรับ 4 คู่

### 6.5 เสียงประจำผี
ทำนองฮัมสั้นของแต่ละตัว (สงบ/หงุดหงิด/โกรธ) — เป็นทั้งบุคลิกและสัญญาณเตือน (D-022)

## 7. ความฮาและความวุ่นวาย (D-006)

- **Active Ragdoll แบบเบา:** สะดุด ชน ตกบันได โดนผีผลัก → ล้มแล้วลุกเร็ว
- **ของแตกได้** + กาววิญญาณ (ผีนับถูกครึ่งเดียว)
- **ผีแกล้งตามนิสัย** 3–5 แบบต่อผี — การแกล้งที่ดีเป็นทั้งมุกและข้อมูล
- **ของย้อนยุคมีลูกเล่น:** พัดลมส่าย ทีวีต้องตบ วิทยุเปิดเพลงเพี้ยน
- **กฎกันน่ารำคาญ:** เหตุการณ์ป่วน ~10–20 วินาที ⚙ · ไม่ทำให้แพ้แบบไม่ยุติธรรม · คูลดาวน์ · เห็นสาเหตุเสมอ · ผลักเพื่อนได้แต่ไม่มีการโยนวนซ้ำ
- **รางวัลพนักงานท้ายงาน** + **รูปเหตุการณ์อัตโนมัติ** + **รีวิวจากผี** (D-007, D-013)

## 9. Multiplayer (D-008, D-026)
- **เทคโนโลยี:** Unity Netcode for GameObjects 2.x + Unity Multiplayer Services (Sessions: Lobby + Relay + Join Code) · Host-authoritative
- **ไหลของผู้เล่น:** เมนูหลัก → สร้างห้อง (ได้รหัส) / ใส่รหัสเข้าห้อง → Lobby ในรถตู้ (Ready, Host เลือกงาน) → งาน → Results → กลับ Lobby
- **ตรวจเวอร์ชันตอนเข้าห้อง** — ไม่ตรงแจ้งให้อัปเดต
- **เข้ากลางงาน:** ไม่ได้ใน v0.1 (เข้าได้เฉพาะใน Lobby)
- **ผู้เล่นหลุด:** งานดำเนินต่อ ของที่ถือหล่น · กลับเข้าได้เมื่อทีมกลับ Lobby
- **Host ออก:** จบงาน ทุกคนกลับเมนูพร้อมข้อความชัดเจน และ **ได้ค่าจ้างของห้องที่ผีรับแล้ว**
- **จำนวนผู้เล่น:** ออกแบบ 6 คน · v0.1 รับรอง 1–4 คน (`Verified`) · 5–6 คน "ทดลอง" มีป้ายใน Lobby
- **ค่าใช้จ่าย:** อยู่ใน Free Tier ของ Unity (ไม่ผูกบัตร) — ถ้าวันหนึ่งเกิน ต้องถามผู้ใช้ก่อนเพิ่มวิธีชำระเงิน

## 10. Voice Chat (D-009, D-010)
- **Vivox** (Unity) · ใช้ Sign-in เดียวกับ Multiplayer
- **ในบ้าน:** ได้ยินเฉพาะคนใกล้ (Proximity) เสียงก้องตามห้อง · **คุยข้ามห้องด้วยวิทยุสื่อสาร** (กดค้าง เสียงซ่า ผีรบกวนได้)
- **Lobby/รถตู้:** ได้ยินทุกคน
- **ผีหูไว** ได้ยินเสียงพูดที่ดังเกินเกณฑ์ ⚙ — ผู้เล่นแต่ละคนปิดได้ ("ให้ผีได้ยินเสียงไมค์ของฉัน")
- เลือกไมค์/ลำโพง · Push-to-Talk / พูดแล้วส่ง · ปรับ/ปิดเสียงรายคน · ไอคอนกำลังพูด · Voice หลุดเกมเล่นต่อได้
- ไม่ใช้ไมค์: วงล้อ Ping + ข้อความด่วน + แชตข้อความ (D-013)
- README แจ้งว่าเสียงพูดผ่านเซิร์ฟเวอร์ Unity/Vivox

## 11. Solo (D-011)
งานเดียวกับ Co-op · **ภาพถ่ายวิญญาณ:** กล้องถ่ายภาพเก็บไว้เปิดดูทีหลัง + โครงร่างจางค้างในห้องสักพัก ฟิล์มมากขึ้น ⚙ · รถเข็น/รอก + ของหนักเบาลง · กลไกที่ต้องทำพร้อมกันใช้ของถ่วง/ตัวตั้งเวลา · หลุดจากตู้เร็วขึ้น · หยุดเกมได้ · ความโกรธเพิ่มช้าลง ⚙ · ใช้ Save เดียวกับ Co-op

## 12. ความก้าวหน้าและรางวัล (D-007, D-025)

- **Multiplayer:** 1–4 คน `Verified` ผ่านอินเทอร์เน็ตโดยผู้ใช้และเพื่อน · Lobby/Ready/เริ่มงาน · สถานะสอดคล้องทุกเครื่อง · หลุด/Host ออก/เวอร์ชันไม่ตรง ทำงานตามข้อ 9 · 5–6 คนเล่นได้แบบทดลอง
- **Voice:** Proximity + วิทยุ + Lobby + ผีหูไวฟังเสียง + ปิดได้ ทำงานจริงผ่านอินเทอร์เน็ต
- **Visual & Audio:** ผ่าน Art Bible (มีภาพหน้าจอ) · ไม่มี Placeholder ค้างใน `ASSET_TRACKER.md` · ผู้ใช้ยืนยันเสียง
- **Localization:** ไทย/อังกฤษถูกต้องทุกหน้าจอ รวมแชตภาษาไทย
- **Technical:** Windows Build จากสคริปต์ · ทดสอบจาก Build จริง · ไม่มี Error สำคัญที่ไม่ได้บันทึก · Test ระบบหลักผ่าน · ตรวจ Performance ด้วย Profiler · License ครบใน `THIRD_PARTY_ASSETS.md` · ไม่มีข้อมูลลับใน Repo
- **Distribution:** Release `SpiritMovers-v0.1.0-Windows.zip` (ชื่อไฟล์ ⚙) · README (ดาวน์โหลด ติดตั้ง SmartScreen/Firewall สร้างห้อง แก้ปัญหา) · เพื่อนที่ไม่รู้เรื่องพัฒนาเกมทำตามจนเล่นได้ · Release Notes (ฟีเจอร์ สเปกขั้นต่ำจากการวัด Known Issues วิธีรายงานบั๊ก)
