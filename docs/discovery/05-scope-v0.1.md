## 5.1 ขนาดเนื้อหา — ✅ ตัดสินแล้ว: **V-M กลาง** (D-025)

| | V-S เล็กมาก | **V-M กลาง ⭐** | V-L ใหญ่ |
|---|---|---|---|
| บ้านสอนเล่น (D-024) | 1 (2 ห้อง) | 1 (2 ห้อง) | 1 (2 ห้อง) |
| บ้านงานจริง (D-020) | 1 — บ้านไม้ใต้ถุนสูง 4 ห้อง | **2** — บ้านไม้ใต้ถุนสูง (4 ห้อง) + ทาวน์เฮาส์เก่า (4–5 ห้อง, มีบันได) | 3 — + ห้องแถวร้านโชห่วย |
| ผีเจ้าบ้าน (D-005, D-019) | 1 (คุณยายขี้อาย) | **2** — คุณยายขี้อาย + ลุงหูไว (สุ่มผีกับบ้านได้ → 4 คู่) + ผีครูฝึก | 3 |
| ระดับงาน | 1 | **2** (ปกติ / ยาก: ห้องและของถูกย้ายมากขึ้น ผีโกรธเร็วขึ้น) | 3 |
| ความหลากหลายต่อรอบ | สุ่มช่องความทรงจำ | สุ่มช่องความทรงจำ + ผี + เหตุการณ์แกล้ง | เหมือน V-M + บ้านมากขึ้น |
| ความยาวต่อรอบ | ~10–15 นาที | **~15–20 นาที** (ตาม D-003) | ~15–25 นาที |
| ของแต่งตัวในร้าน (D-007) | 6 | **12** (หมวก 4 · สีชุดยูนิฟอร์ม 4 · เครื่องประดับ 4) + Emote 4 (ไหว้ผี, ชี้, โบกมือ, เต้น) | 24 |
| ยศบริษัท | 2 | **3** (ฝึกงาน → พนักงาน → หัวหน้าทีม) — ยศ 2 ปลดล็อกบ้านหลังที่ 2, ยศ 3 ปลดล็อกงานยาก | 4 |
| ความเสี่ยงทำไม่เสร็จ | ต่ำ | กลาง | **สูง** |
| เล่นซ้ำก่อนเบื่อ (ประมาณการ) | 1–2 คืน | หลายคืน | นานกว่า |

**คำแนะนำ V-M** — บ้าน 2 หลัง × ผี 2 ตัว × 2 ระดับ + การสุ่มความทรงจำ ทำให้เพื่อนเล่นซ้ำได้หลายคืน โดยงานศิลป์ (บ้าน 2 หลัง + ผี 3 ตัว) ยังอยู่ในขอบเขตที่ทำได้ · บ้านที่ 2 มีบันได ทดสอบมุก "ยกของขึ้นลงบันได" (D-015)

## 5.2 จำนวนผู้เล่นที่ทดสอบให้มั่นคงใน v0.1 — ✅ ตัดสินแล้ว: **P4 มั่นคง 1–4 คน + 5–6 คนแบบทดลอง** (D-026)

| | P4. มั่นคง 1–4 คน + 5–6 คนแบบทดลอง ⭐ | P6. มั่นคง 1–6 คนเต็ม |
|---|---|---|
| ออกแบบรองรับ | 6 คน (ทุกระบบ) | 6 คน |

## 5.3 ระบบใน v0.1 (สรุปจาก D-003–D-024 — ผู้ใช้อนุมัติรายข้อแล้ว รวมไว้ให้ตรวจที่ G4)

### Gameplay
- งานเดี่ยว (Restore) · ออกก่อนได้รับค่าจ้างตามห้องที่ผีรับ · ผีไล่ออกเมื่อโกรธเต็ม (D-003)
- กล้องวิญญาณ · ผีพยักหน้า (กริ่ง) · สุ่มช่องความทรงจำ · ปัญหา: ถูกย้าย/ซ่อน/ลำดับ/ถูกสิง (+ ของหลอก ถ้าทัน) · Hint ไล่ระดับ (D-004)
- ผีเจ้าบ้าน 1 ตัว/งาน · ความโกรธ 5 ขั้น · ตู้ความทรงจำ · สัญญาณเตือน · Jumpscare ลดได้ (D-005)
- ฟิสิกส์ยกของ · Active Ragdoll เบา · ของแตก + กาววิญญาณ · ผีแกล้ง 3–5 แบบ/ชนิด · ไหว้ผี (D-006)
- เงิน · ร้านของแต่งตัว · ยศ · รางวัลพนักงาน · สถิติชุดเล็ก · อัลบั้มผี (D-007)
- Solo: ภาพถ่ายวิญญาณ, รถเข็น/รอก, หลุดจากตู้เร็วขึ้น, ปรับขนาดงานตามจำนวนผู้เล่น, หยุดเกมได้ (D-011)
- เครื่องมือ: กล้อง, วิทยุ, รถเข็น/รอก, กาว, ไฟฉายหมวก, กริ่ง · มือ 2 ข้าง + เข็มขัด 1 ช่อง + กล่องทีม (D-021)
- Tutorial: งานฝึกงาน + ผีครูฝึก · คำแนะนำตามสถานการณ์ (D-024)

### Online / Voice
- Unity NGO 2.x + Multiplayer Services (Lobby + Relay + Join Code) · Host-authoritative · ตรวจเวอร์ชัน · จัดการผู้เล่นหลุด/Host ออก (D-008)
- Vivox: ใกล้ได้ยิน + วิทยุ + Lobby ได้ยินทุกคน · ผีหูไวฟังเสียงพูด (ปิดได้รายคน) · เลือกไมค์ · PTT/VA · ปิดเสียงรายคน (D-009, D-010)
- แชตข้อความ (ไทย IME) (D-013)

### Presentation
- กล้องบุคคลที่หนึ่ง + สลับบุคคลที่สาม (D-014) · ควบคุมแม่น (D-015)
- Art: "บ้านซีด → ผีพอใจ → สีกลับมา" (D-017) · ตัวละคร CH3 (D-018) · ผี GH2 (D-019) · ฉากไทย/เอเชีย 80–90 (D-020)
- เสียง: เงียบ + เพลงจากของในบ้าน + เสียงฮัมผี (D-022)
- UI: HUD น้อย + ใบสั่งงาน + หน้าจอ: เมนูหลัก, Lobby, HUD, Results, แต่งตัว, อัลบั้ม, Settings, Error (D-023)
- รูปเหตุการณ์อัตโนมัติ + รีวิวจากผี (D-013)

### Technical / Quality
- ภาษาไทย (ค่าเริ่มต้น) / อังกฤษ ผ่าน Localization ทุกข้อความ (MASTER_PROMPT 1.3)
- Accessibility ชุดพื้นฐานครบ (D-012)
- Save ในเครื่อง · Settings ต่อเครื่อง · ปุ่มสร้างชุดรายงานบั๊ก (D-013)
- Windows 64-bit เท่านั้น · แจกผ่าน GitHub Releases · README + คู่มือ SmartScreen/Firewall (MASTER_PROMPT 1.4)
