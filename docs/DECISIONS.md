## D-003 · 2026-10-29 · G3-A Core Gameplay — โครงสร้างรอบการเล่น (ประเภท A)
- **ประเด็น:** หนึ่งรอบการเล่นมีโครงสร้างอย่างไร อะไรเชื่อมรอบต่อรอบ
- **ทางเลือก:** A1 งานเดี่ยว · A2 สัญญาต่อเนื่อง (รันหลายบ้าน + คะแนนบริษัท) · A3 บ้านเดียวหลายคืน — รายละเอียด `docs/discovery/03-systems.md` หัวข้อ A
- **สิ่งที่เลือก:** **A1. งานเดี่ยว** — 1 บ้าน = 1 งาน ~15–20 นาที, เงินในเกมใช้ปลดล็อก, ความยากตามระดับงาน, เล่นซ้ำจากการสุ่มความทรงจำ/ผี/เหตุการณ์
- **ผู้ตัดสิน:** ผู้ใช้ (ตรงกับคำแนะนำ)
- **รวมค่าเริ่มต้นที่เสนอพร้อมกันและผู้ใช้ไม่ได้แย้ง:** วัตถุประสงค์ = ความพอใจของผีถึงเกณฑ์โดยจัดห้องให้ผี "รับห้อง" · Loop: บรีฟในรถตู้ → สำรวจ → จัดห้อง → ส่งผี → ค่าจ้าง · ไม่จำกัดเวลาตายตัว แรงกดดันจากความโกรธ · ออกก่อนได้รับค่าจ้างตามห้องที่ผีรับ · แพ้ = ผีไล่ออก (Ragdoll) ค่าจ้างลด ไม่เสียของถาวร · บ้านสอนเล่น + วิทยุจากหัวหน้า
- **v0.1:** งาน Restore เท่านั้น · **ภายหลัง:** งาน "ย้ายบ้านให้ผี", ผีหลายตัวความทรงจำขัดกัน, งานมีเนื้อเรื่อง (แบบ A3), โหมดรันต่อเนื่อง (แบบ A2)
- **เหตุผล:** คอนเทนต์ถึง v0.1 ต่ำสุด, เซสชันสั้น, ห่างจากโครง Quota run ของเกมแรงบันดาลใจ, ต่อยอดได้

## D-004 · 2026-10-29 · G3-B Puzzle System — ภาษาของปริศนา (ประเภท A)
- **ประเด็น:** ผู้เล่นรู้ได้อย่างไรว่าห้องเดิมหน้าตาเป็นแบบไหน
- **ทางเลือก:** B1 รูปถ่ายความทรงจำ · B2 เบาะแสเชิงตรรกะ · B3 กล้องวิญญาณ + เบาะแสหลายชั้น — รายละเอียด `docs/discovery/03-systems.md` หัวข้อ B
- **สิ่งที่เลือก:** **B3. กล้องวิญญาณ + เบาะแสหลายชั้น**
  - กล้อง/ตะเกียงวิญญาณ: เห็นภาพซ้อนโปร่งแสงของห้องเดิม เฉพาะคนถือ, ส่องได้จำกัดครั้ง, ใช้บ่อยผีหงุดหงิด, ส่งต่อได้
  - ผีพยักหน้า: เรียกผีแล้วผีบอก "จำนวน" ของที่วางถูก (ไม่บอกชิ้นไหน), เรียกบ่อยผีหงุดหงิด
  - รูปถ่ายชิ้นส่วน/เบาะแสตรรกะเป็นชั้นเสริมสำหรับของชิ้นสำคัญ
- **ผู้ตัดสิน:** ผู้ใช้ (ตรงกับคำแนะนำ)
- **รวมค่าเริ่มต้นที่เสนอพร้อมกันและผู้ใช้ไม่ได้แย้ง:** ตัดสินจากสภาพห้อง (โซน + ทิศทาง + ระยะคลาดเคลื่อน) · สุ่ม "ช่องความทรงจำ" ทุกรอบ · ประเภทปัญหา v0.1: ของถูกย้าย/ซ่อน/ลำดับ/ถูกสิง (ของหลอกถ้าทัน) · Hint ไล่ระดับจากวิทยุหัวหน้า แลกค่าจ้าง · ไม่มีอาชีพตายตัวใน v0.1
- **ภายหลัง:** ผีหลายตัวความทรงจำขัดกัน, ล็อกห้องด้วยรหัสจากความทรงจำ, ปริศนาเฉพาะชนิดผี
- **ความเสี่ยงที่ต้องติดตาม:** Shader ภาพซ้อนต้องดีพอเป็นภาพจำ (พิสูจน์ช่วง Art/Prototype) · ต้องคุมไม่ให้คนถือกล้องคนเดียวแบกเกม

## D-005 · 2026-10-29 · G3-C Ghost & Horror — ใครคือภัยคุกคาม (ประเภท A)
- **ประเด็น:** ภัยคุกคามหลักมาจากไหน
- **ทางเลือก:** C1 ผีเจ้าบ้านคือภัยเอง · C2 ผีเจ้าบ้าน (ลูกค้า) + ผีจรจัด (ตัวไล่ล่า) · C3 บ้านคือภัย ไม่มีการไล่ล่า — รายละเอียด `docs/discovery/03-systems.md` หัวข้อ C
- **สิ่งที่เลือก:** **C1. ผีเจ้าบ้านคือภัยเอง** — ผีตัวเดียวต่องาน, ยิ่งโกรธยิ่งอันตราย, ออกล่าเองตอนอาละวาด
- **ผู้ตัดสิน:** ผู้ใช้ (ตรงกับคำแนะนำ)
- **รวมค่าเริ่มต้นที่เสนอพร้อมกันและผู้ใช้ไม่ได้แย้ง:** ความโกรธ 5 ขั้น (สงบ → หงุดหงิด → โมโห → อาละวาด → ไล่ออก) เพิ่มจากความผิดพลาด/เสียง/ใช้กล้องหรือเรียกผีบ่อย/เวลา ลดเมื่อผีรับห้อง · ถูกจับ = ขังใน "ตู้ความทรงจำ" เพื่อนช่วยได้หรือหลุดเองแลกค่าจ้าง, ทุกคนถูกจับ = ไล่ออก · สัญญาณเตือนทางเสียง/ภาพทุกขั้น · Jumpscare น้อย มีเหตุ และลดได้ใน Accessibility
- **v0.1:** ผีเจ้าบ้าน 2 ชนิด — ผีขี้อาย (ขยับเฉพาะตอนไม่มีใครมอง) · ผีหูไว (ล่าตามเสียง) · **ภายหลัง:** ผีกลัวแสง, ผีขี้หวง, ผีขี้ลืม, "ผีจรจัด" (จาก C2) เป็นเหตุการณ์ในงานระดับยาก
- **ค้างไปหัวข้อ G:** ผีตอบสนองต่อเสียงพูดจากไมค์หรือไม่ (ขึ้นกับบริการ Voice)
- **ความเสี่ยงที่ต้องติดตาม:** ผู้เล่นอาจรู้สึกขัดที่ "ลูกค้าไล่ฆ่า" → การเล่าเรื่องต้องสื่อว่าผีสับสน/โกรธ ไม่ใช่ชั่วร้าย
