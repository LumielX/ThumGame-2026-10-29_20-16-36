## M3A — ผลและเรื่องที่ยกไปแผนถัดไป (รีวิว 2026-10-31)
M3A เสร็จ: Tests 88/88 · รีวิวโดย Reviewer ใหม่: Critical 0 · Important 6 แก้แล้วพร้อม Test (เลือกห้องที่ใช้ได้ก่อนสุ่ม, บ้านที่ไม่มีช่องใช้ได้ → Exception, จุดเริ่มไม่ซ้ำกัน, ของครบทุกชิ้นรับห้องเสมอแม้มีของกาว, ค่า Default ไม่แชร์กัน)

ข้อเล็กที่ยกไปให้ M3C (ตอนต่อ Runtime) ต้องจัดการ:
1. รวมตัวคูณความโกรธ `difficulty.AngerMultiplier × PlayerCountScaling.AngerMultiplier` ในจุดเดียว (Factory) — ห้ามให้ผู้เรียกคูณเอง
2. ตัวโหลด `HouseDefinition → HouseLayout` ต้องคงลำดับห้อง/ช่อง/จุดตามที่ออกแบบ (ห้ามใช้ `FindObjectsOfType` ที่ลำดับไม่แน่นอน) · พิจารณาใส่ Hash ของข้อมูลบ้าน/ระดับใน `JobPlan` กันเครื่องที่ข้อมูลต่างกัน
3. แปลง Rotation ที่เป็นศูนย์ (0,0,0,0) เป็น Identity ตอนโหลด — ไม่งั้นช่องนั้นไม่มีวันถูก
4. ตรวจ Config ตอนโหลด: Min ≤ Max ของระดับงาน, `AngerConfig.Max` ≥ เกณฑ์ขั้นสุดท้าย
5. Host ออกช่วง Briefing: `JobProgress.LeaveEarly` ไม่ทำงานใน Briefing (`Ending` ยัง null) — ตัดสินใน M3C/M4
6. ตำแหน่งเริ่มอาจนับว่าถูกอยู่แล้ว (จุดสำรอง +1 ม. เมื่อ Tolerance ≥ 1 ม. / จุดซ่อนตรงกับตำแหน่งจริง) — ตรวจตอนออกแบบบ้าน
7. `PayoutCalculator` จำกัดช่วง Hint (≥0) และดาว (0–3)
8. `Wai` ตอนความโกรธ 0 ใช้สิทธิ์ห้องนั้นไปโดยไม่มีผล — ตัดสินว่าควรเป็นอย่างไรตอนทำ Emote
9. `Apply_AfterEviction_IsIgnored` ควรเรียก `Apply` จริงด้วย Config ที่ Max สูงกว่าเกณฑ์สุดท้าย

## M3B — ผลและเรื่องที่ยกไป (รีวิว 2026-10-31)
M3B เสร็จ (`Tested`): EditMode 109 · PlayMode 20 · Relay 6 สถานการณ์ผ่านทั้ง 0 ms และ 150 ms ต่อทาง · รีวิว: Critical 0 · Important 4 แก้แล้ว (ยก 2 คนเดินแยกแล้วปล่อยเอง, คนถือหายแล้วของไม่ลอยค้าง, พักการตรวจ 1 วินาทีหลังเปลี่ยนเจ้าของ, เพิ่มสถานการณ์ทดสอบฝั่ง Client) · พบ: Build ห้ามใช้ `-nographics`

ข้อเล็กที่ยกไป:
1. (M3C) ล้างแรงโยนที่ค้างเมื่อมีคนยกใหม่ก่อน FixedUpdate — `Carryable.TryAddCarrier`
2. (M3C) อย่ามอบ Ownership ให้ Client ที่กำลังหลุด — ตรวจ `ConnectedClientsIds`
3. (M3C) Host ตรวจมุม/สิ่งกีดขวางตอนยก ไม่ใช่แค่ระยะ (TECHNICAL_DESIGN §6)
4. (M4) ผู้เล่นอื่นเห็นตัวละครไถลจากจุดกำเนิดตอนเกิด — ใช้ `NetworkTransform.Teleport` หรือให้ Server กำหนดจุดเกิด
5. (M4) คืนกล้อง/เคอร์เซอร์/ป้ายคำแนะนำเมื่อออกจาก Session
6. (M4) ผู้เล่นที่เข้ากลางทางไม่เห็นว่าใครถืออะไรอยู่ (NetworkList ตอนซิงก์แรกไม่ยิง OnListChanged)
7. (M3C) `Carryable.Interact` ไม่ใช้ `by` · `Carriers`/`TryGetHoldPoint` สร้าง List ทุกครั้ง · `ForceDropped` เป็น static event ที่ไม่มีใครล้าง
8. (M3D) ท่าย่อไม่ซิงก์ — ความสูง Collider ของผู้เล่นอื่นยังยืนอยู่ (มีผลกับผีมองเห็น/การซ่อน)
