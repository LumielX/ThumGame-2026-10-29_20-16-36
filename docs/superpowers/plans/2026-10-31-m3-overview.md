# M3 Playable Prototype — ภาพรวมแผน

> Spec: `docs/PROJECT_PLAN.md` (M3) · `docs/GDD.md` §4–8 · `docs/TECHNICAL_DESIGN.md` §3–7 (อนุมัติ G5, D-029) · G6 ผ่านแบบมีเงื่อนไข (D-040)
> เกณฑ์ตรวจรับ M3: 2–4 Instance เล่นจบงานได้ · EditMode Test ของ Core ผ่าน · ไม่มี Desync ของสถานะงานในการทดสอบ 10 รอบ

M3 มี 4 ระบบย่อยที่ทดสอบแยกกันได้ จึงแบ่งเป็น 4 แผน ทำตามลำดับ (แผนหลังใช้ Interface ของแผนก่อน):

| แผน | ขอบเขต | ผลที่ทดสอบได้ | ไฟล์แผน |
|---|---|---|---|
| **M3A Core Job Logic** | Placement/RoomEvaluator · AngerModel · JobGenerator · PayoutCalculator · JobProgress (C# ล้วน) | EditMode Tests | `2026-10-31-m3a-core-job-logic.md` |
| M3B Player & Interaction | Character Controller (เดิน/วิ่ง/ย่อ/กระโดดเตี้ย) · `IInteractable` · ยก/วาง/หมุน/โยน (วิธี B, D-034) · Input Actions · ห้องทดสอบ Greybox | PlayMode + 2 Instance ผ่าน Relay | เขียนหลัง M3A |
| M3C Job Runtime | `HouseDefinition`/`MemorySlot` (ScriptableObject → `HouseLayout`) · รื้อบ้านตาม `JobPlan` · ประเมินห้องบน Host · กริ่งผีพยักหน้า · ผีรับห้อง + `Restoration` · ใบสั่งงานขั้นต้น · จบงาน 3 แบบ + Results | PlayMode + Multi-instance 10 รอบ | เขียนหลัง M3B |
| M3D Ghost & Tools | ผีขี้อาย (Placeholder) บน Host · ความโกรธ → พฤติกรรม 5 ขั้น · ตู้ความทรงจำ · กล้องวิญญาณ (Shader ขั้นต้น) · `NoiseEvent` | PlayMode + Multi-instance | เขียนหลัง M3C |

แต่ละแผนเขียนตอนเริ่มทำ (ไม่เขียนล่วงหน้าทั้งหมด) เพื่อใช้สิ่งที่เรียนรู้จากแผนก่อน
